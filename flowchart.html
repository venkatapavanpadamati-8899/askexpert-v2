🤖 AI Fix Center & Safety Gating Pipeline

Automated issue reporting, technical diagnosis, and zero-autonomous-execution safety model

flowchart TD
    R1["User, Expert, or Admin encounters an issue"] --> R2["Global Modal: reportIssueModal.js
(Category: bug/feature/security, severity)"]
    R2 -->|Insert| DB1["Supabase Table: issue_reports
(status: 'pending_ai')"]

    DB1 --> R3["AI Issue Analyzer: aiIssueAnalyzer.js
(Root-cause diagnosis, diff generation)"]
    R3 -->|Insert| DB2["Supabase Table: ai_fix_proposals
(status: 'pending_review')"]

    DB2 --> R4["admin-ai-fix-center.html
(Admin inspects unified diff & files)"]
    R4 --> R5{"Admin Decision"}

    R5 -->|REJECT| R6["Proposal Status: REJECTED
(No code applied)"]
    R5 -->|APPROVE| R7["Admin Approves with Notes & Signature"]

    R7 --> DB3["Supabase Table: admin_approvals
(Authorized execution)"]
    DB3 --> DB4["Supabase Table: audit_logs
(Immutable cryptographic trail)"]
    DB4 --> R8["Automated Notification Sent to Reporter"]

💬 Multi-Tier Chat Access Control & Privacy Engine

Server-backed privacy gating, rate limiting, and realtime participant security

flowchart TD
    C1["User A opens chat with User B
(chat.html?recipient=User_B_ID)"] --> C2["Fetch User B Privacy Settings
(privacy_settings table)"]
    C2 --> C3{"Check: who_can_message"}

    C3 -->|'nobody'| C4["BLOCK: 'This user has disabled incoming direct messages.'"]
    C3 -->|'verified_experts_only'| C5{"Is User A a Verified Expert?"}
    C5 -->|No| C6["BLOCK: 'Only verified specialists can message this user.'"]
    C5 -->|Yes| C7["ALLOW CONVERSATION"]
    C3 -->|'everyone'| C7

    C7 --> C8["Check Rate Limit Guard
(Max 10 messages / 10s)"]
    C8 -->|Threshold Exceeded| C9["Throttle message (HTTP 429 warning)"]
    C8 -->|Within Limits| C10["Dispatch via Supabase Realtime
(messages table)"]
